# Ekips Prime Pro Tools – Überblick

Dieses Repository enthält die Werkzeuge, mit denen du auf deinem Computer
Ekips-Prime-Pro-Programme für den LEGO® SPIKE™ Prime Hub schreibst und
prüfst.

| Werkzeug | Was es macht |
|---|---|
| `ekips` | Kommandozeilenprogramm: prüft Programme, später startet es sie im Simulator und überträgt sie auf den Hub |
| `ekips-lsp` | Language Server: zeigt Fehler schon beim Tippen, erklärt Wörter und schlägt Code im Editor vor |
| Simulator | Fährt einen virtuellen Roboter auf einer FLL-Matte (geplant) |
