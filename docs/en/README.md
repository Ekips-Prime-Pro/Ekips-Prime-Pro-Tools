# Ekips Prime Pro Tools – Overview

This repository contains the tools you use on your computer to write and
check Ekips Prime Pro programs for the LEGO® SPIKE™ Prime hub.

| Tool | What it does |
|---|---|
| `ekips` | Command-line tool: checks programs, later runs them in the simulator and uploads them to the hub |
| `ekips-lsp` | Language server: shows errors while you type, explains words and suggests code in your editor |
| Simulator | Drives a virtual robot on an FLL mat (planned) |
