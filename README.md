# Ekips Prime Pro – Tools

Command-line tool, simulator and language server for
[Ekips Prime Pro](https://github.com/Ekips-Prime-Pro/Ekips-Prime-Pro-Core).

> **Status:** not started yet.

## Plan

| Part | Purpose |
|---|---|
| `ekips` CLI | `check`, `run --sim`, `upload`, `monitor`, `flash-firmware`, `backup-firmware` |
| Simulator | 2D robot simulation on an FLL mat (also as WebAssembly for the browser) |
| Language server | Errors, autocomplete and hover docs for the VS Code extension |

All parts depend on the crates in Ekips-Prime-Pro-Core (pinned to tags).
